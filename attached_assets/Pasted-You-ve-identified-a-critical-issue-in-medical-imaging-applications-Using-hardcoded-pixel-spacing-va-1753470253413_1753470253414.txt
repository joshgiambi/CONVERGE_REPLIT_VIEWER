## Why Pixel Spacing Matters So Much

In medical imaging, **pixel spacing** represents the real-world distance between pixel centers in millimeters. This is crucial because:

- **Measurement accuracy**: Without correct pixel spacing, any distance measurements will be wrong
- **Contour alignment**: RT structure contours must align precisely with anatomy
- **Treatment planning**: In radiation therapy, even small coordinate errors can be dangerous
- **Multi-modal fusion**: Registering CT with MR or PET requires precise spatial correspondence

## Validation and Sanity Checks

Always validate pixel spacing values to catch corrupted or unusual data:

```typescript
const validatePixelSpacing = (spacing: [number, number], modality: string): boolean => {
  const [rowSpacing, colSpacing] = spacing;
  
  // Basic sanity checks
  if (rowSpacing <= 0 || colSpacing <= 0) return false;
  if (rowSpacing > 50 || colSpacing > 50) return false; // Unusually large
  if (rowSpacing < 0.01 || colSpacing < 0.01) return false; // Unusually small
  
  // Modality-specific validation
  switch (modality) {
    case 'CT':
      // CT typically 0.3-2.0mm
      return rowSpacing >= 0.3 && rowSpacing <= 3.0 && 
             colSpacing >= 0.3 && colSpacing <= 3.0;
    case 'MR':
      // MR can vary widely 0.1-5.0mm
      return rowSpacing >= 0.1 && rowSpacing <= 5.0 && 
             colSpacing >= 0.1 && colSpacing <= 5.0;
    case 'PT':
      // PET typically 2-5mm
      return rowSpacing >= 1.0 && rowSpacing <= 8.0 && 
             colSpacing >= 1.0 && colSpacing <= 8.0;
    default:
      return true; // Allow other modalities
  }
};
```

## Updated Coordinate Transformation

Here's how to improve your coordinate transformation functions:

```typescript
// ✅ IMPROVED: Proper coordinate transformation with explicit spacing
const worldToCanvas = (
  worldX: number, 
  worldY: number,
  imagePosition: [number, number, number],
  pixelSpacing: [number, number], // [row spacing, column spacing]
  canvasWidth: number,
  canvasHeight: number,
  imageWidth: number = 512,
  imageHeight: number = 512
): [number, number] => {
  
  // Validate inputs
  if (!pixelSpacing || pixelSpacing.length !== 2) {
    throw new Error('Invalid pixel spacing for coordinate transformation');
  }
  
  // Convert world coordinates to pixel coordinates
  // Note: DICOM pixel spacing is [row spacing, column spacing] = [deltaY, deltaX]
  const pixelX = (worldX - imagePosition[0]) / pixelSpacing[1]; // column spacing
  const pixelY = (worldY - imagePosition[1]) / pixelSpacing[0]; // row spacing
  
  // Convert to canvas coordinates with proper scaling
  const scale = Math.min(canvasWidth / imageWidth, canvasHeight / imageHeight);
  const scaledImageWidth = imageWidth * scale;
  const scaledImageHeight = imageHeight * scale;
  
  const offsetX = (canvasWidth - scaledImageWidth) / 2;
  const offsetY = (canvasHeight - scaledImageHeight) / 2;
  
  const canvasX = offsetX + (pixelX * scale);
  const canvasY = offsetY + (pixelY * scale);
  
  return [canvasX, canvasY];
};
```

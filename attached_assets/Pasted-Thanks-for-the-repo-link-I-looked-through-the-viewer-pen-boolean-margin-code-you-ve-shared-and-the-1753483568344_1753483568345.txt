1.2 js-angusj-clipper usage consistency

In PenToolUnifiedV2 you correctly load the WASM instance and construct via new clipperLib.instance.Clipper(new IoManager()). In your helpers you also use the global classes (new clipperLib.Clipper(), new clipperLib.Paths()), which don’t exist in the WASM build and can silently fail.
Fix: centralize a singleton loader and always use the instance.* classes.

// lib/geometry/clipper/instance.ts
import * as ClipperLib from 'js-angusj-clipper';

let _clip: Awaited<ReturnType<typeof load>> | null = null;

export async function load() {
  if (_clip) return _clip;
  const lib = await ClipperLib.loadNativeClipperLibInstanceAsync(
    ClipperLib.NativeClipperLibRequestedFormat.WasmWithAsmJsFallback
  );
  const i = lib.instance;
  _clip = {
    i,
    newClipper: () => new i.Clipper(new i.IoManager()),
    newPath: () => new i.Path(),
    newPaths: () => new i.Paths(),
  };
  return _clip;
}

Then in all boolean helpers:

const { i, newClipper, newPath, newPaths } = await load();
const clipper = newClipper();
const subject = newPath(); const clip = newPath(); const solution = newPaths();

This removes the “works here / breaks there” inconsistency and the occasional “nothing happens on close” symptom.

Today, some code concatenates points and treats a slice like one long ring. That causes ghost connections and “overlaps but not unioned”.

	•	For union/subtract, union all slice polys with the new polygon, then replace only the affected slice’s set with the result paths.

2.3 Brush → union (fix “overlapping outputs”)

The brush path check uses a nearest-point distance heuristic; sometimes it misses intersection → you end up with overlapping contours.
Fix: generate a stroke ribbon polygon from the sampled brush path and union it with the slice multipolygon via Clipper every time. You already have mergeBrushWithContour—swap its internals to delegate to the Clipper union path (behind a flag).

7) Example: unified boolean helper (drop-in)

// lib/geometry/boolean/clipper.ts
import { load } from '../clipper/instance';

const SCALE = 1e4; // safer, less noise
const EPS_AREA = 1e-3;

export async function diff(subjects: number[][], clip: number[], z: number) {
  const { i, newClipper, newPath, newPaths } = await load();
  const clipper = newClipper();
  const sol = newPaths();

  const toPath = (flat: number[]) => {
    const p = newPath();
    for (let k=0; k<flat.length; k+=3) p.push({X: Math.round(flat[k]*SCALE), Y: Math.round(flat[k+1]*SCALE)});
    return p;
  };

  subjects.forEach(s => clipper.AddPath(toPath(s), i.PolyType.ptSubject, true));
  clipper.AddPath(toPath(clip), i.PolyType.ptClip, true);

  clipper.Execute(i.ClipType.ctDifference, sol, i.PolyFillType.pftNonZero, i.PolyFillType.pftNonZero);

  const out: number[][] = [];
  for (let pi=0; pi<sol.size(); pi++) {
    const path = sol.get(pi);
    const ring: number[] = [];
    for (let j=0; j<path.size(); j++) {
      const pt = path.get(j);
      ring.push(pt.X/SCALE, pt.Y/SCALE, z);
    }
    if (ring.length >= 9 && Math.abs(area(ring)) > EPS_AREA) out.push(ring);
  }
  sol.delete(); clipper.delete();
  return out;
}

function area(flat: number[]) {
  let a = 0;
  for (let i=0; i<flat.length; i+=3) {
    const ni = (i+3) % flat.length;
    a += flat[i]*flat[ni+1] - flat[ni]*flat[i+1];
  }
  return 0.5*a;
}

Call this from your handleContourUpdate('pen_boolean_operation'), converting the current slice’s contour set to subjects.

2) High-impact, low-risk fixes (boolean + margin flows)

A) Make boolean ops consistent (one Clipper path only)

Right now you have a robust Clipper implementation and a simple “convex hull / point filter” implementation with the same export names. That can cause:
	•	No-ops (looks like “nothing happens” after closing the pen loop).
	•	Overlaps instead of boolean merges (brush).

Safe fix:
	•	Split into two modules and one public facade:
	•	lib/clipper-adapter.ts – one way to get a Clipper instance:
	•	For js-angusj-clipper, prefer loadNativeClipperLibInstanceAsync and use instance.Path/Paths/Clipper. Wrap this behind getClipper() so other code doesn’t care which API surface is used.
	•	lib/contour-boolean-clipper.ts – only the Clipper-based union/subtract/intersect/xor, with:
	•	SCALE = 1e4 (or 1e3) – large enough for integer precision but not excessively big.
	•	CleanPolygon (or CleanPolygons) after every op.
	•	PolyFillType.pftNonZero for medical contours (holes are supported).
	•	lib/contour-boolean.ts – facade that re-exports the Clipper versions. If you really need a fallback, export them under different names (e.g., unionFallbackHull) so they can’t shadow the real ones.
	•	Update imports everywhere to come from lib/contour-boolean (the facade).

While there:
	•	Add a small helper to convert between flat [x,y,z] arrays and Clipper’s {X,Y} with z carried separately.
	•	Call EnsureOrientation/ReversePath for holes if needed; or just rely on pftNonZero and clean.

B) Always clean/simplify polygons around boolean ops
	•	Before and after boolean operations, apply:
	•	CleanPolygon (tolerance ≈ 0.05–0.2 mm in world units × SCALE)
	•	Optional SimplifyPolygon (if available) after unions to remove spike artifacts from brush strokes.
	•	After subtract, keep multiple resulting contours per slice (you’re already doing that). Ensure renderer fills with even-odd rule (see below).

C) Fix brush overlaps that “don’t boolean”

That happens when the brush polygon isn’t being unioned robustly or rings self-intersect.

Adjust the flow:
	1.	Convert brush path → closed polygon (ensure last==first or explicitly close).
	2.	CleanPolygon on the brush polygon.
	3.	If there’s an existing contour on that slice, always do a Clipper union (subject=existing, clip=brush) rather than the “distance < threshold” heuristic. The distance check can remain as a performance early-exit, but don’t rely on it for correctness.
	4.	After union, CleanPolygons and store.

This change keeps your UI behavior but removes those “overlapping outputs”.

D) Margin (uniform & asymmetric) that respects mm and holes

Your margin code currently calls growContour + smoothContour. For medical “margins” (Eclipse-style), you’ll get better shape fidelity by using ClipperOffset:
	•	Add offsetContours(points[], marginMm) backed by ClipperOffset (with miter limit and round joins).
	•	Use world mm → scale → integer offset → back to world.
	•	After offset, CleanPolygons then optional smoothing (light).
	•	For asymmetric margins, compute directional offsets by splitting a contour into half-spaces (or apply applyDirectionalGrow first, then offsetContours with a small uniform value to re-regularize edges).

This will make margins robust (no gaps/self-intersections) and preserve holes.

3) One source of truth for “slice equality” & drawing holes

A) Slice matching

You currently mix:
	•	exact z-equality (μm rounding)
	•	±0.5 mm tolerance
	•	“sliceThickness/2” tolerance

Safe consolidation:
Create lib/slices.ts:

export function sameSlice(z1: number, z2: number, sliceThickness?: number) {
  const tol = Math.max(0.5, (sliceThickness ?? 1) * 0.5); // mm
  return Math.abs(z1 - z2) <= tol;
}

Use this everywhere (viewer render, pen tool, brush tool, handlers).

B) Holes rendering on Canvas

If subtraction creates donut shapes (outer ring + inner hole), you need even-odd fill:

ctx.fill("evenodd");

If you must support older canvases, draw outer ring CCW and holes CW (reverse winding) then normal fill().

7) Quick code patterns to drop in

Clipper adapter (single source):

// lib/clipper-adapter.ts
import * as Clipper from 'js-angusj-clipper';

export type ClipperAPI = {
  instance: any; // WASM instance types
  Path: any;
  Paths: any;
  Clipper: any;
  PolyType: any;
  ClipType: any;
  PolyFillType: any;
  CleanPolygon: (path: any, dist: number) => any;
  CleanPolygons: (paths: any, dist: number) => any;
  ClipperOffset?: any;
};

let cached: ClipperAPI | null = null;

export async function getClipper(): Promise<ClipperAPI> {
  if (cached) return cached;
  const lib = await Clipper.loadNativeClipperLibInstanceAsync(
    Clipper.NativeClipperLibRequestedFormat.WasmWithAsmJsFallback
  );
  cached = {
    instance: lib.instance,
    Path: lib.instance.Path,
    Paths: lib.instance.Paths,
    Clipper: lib.instance.Clipper,
    PolyType: lib.instance.PolyType,
    ClipType: lib.instance.ClipType,
    PolyFillType: lib.instance.PolyFillType,
    CleanPolygon: lib.instance.CleanPolygon,
    CleanPolygons: lib.instance.CleanPolygons,
    ClipperOffset: lib.instance.ClipperOffset,
  };
  return cached;
}

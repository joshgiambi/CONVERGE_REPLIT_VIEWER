# DICOM Spatial Registration Implementation Guide

## Overview
Your DICOM registration file contains a **4x4 transformation matrix** that defines how to transform MRI coordinates to match CT coordinates for proper image fusion and overlay.

## Understanding the Registration Object

## Step-by-Step Implementation

### Step 1: Understand the Coordinate Systems

**DICOM Patient Coordinate System (RCS)**:
- **X-axis**: Right to Left (positive = patient's left)
- **Y-axis**: Anterior to Posterior (positive = patient's back)  
- **Z-axis**: Inferior to Superior (positive = patient's head)

### Step 2: Load and Identify Image Sets

```python
# Pseudocode for your agent implementation
def load_image_sets(registration_file):
    # Parse registration object
    reg_data = parse_dicom_registration(registration_file)
    
    # Extract transformation matrix
    transform_matrix = reg_data.get_transformation_matrix()
    
    # Identify CT and MR image sets from referenced SOP instances
    ct_images = []
    mr_images = []
    
    for ref in reg_data.referenced_images:
        if ref.sop_class == "1.2.840.10008.5.1.4.1.1.2":  # CT
            ct_images.append(ref)
        elif ref.sop_class == "1.2.840.10008.5.1.4.1.1.4":  # MR
            mr_images.append(ref)
    
    return ct_images, mr_images, transform_matrix
```

### Step 3: Convert Image Coordinates to Patient Coordinates

For each DICOM image, you need to create a transformation from image indices (i,j,k) to patient coordinates (x,y,z):

```python
def image_to_patient_transform(dicom_header):
    """
    Create transformation matrix from image coordinates to patient coordinates
    """
    # Extract DICOM orientation parameters
    image_position = dicom_header.ImagePositionPatient  # [x, y, z] of first voxel
    image_orientation = dicom_header.ImageOrientationPatient  # [Xx, Xy, Xz, Yx, Yy, Yz]
    pixel_spacing = dicom_header.PixelSpacing  # [row_spacing, col_spacing]
    slice_thickness = dicom_header.SliceThickness or dicom_header.SpacingBetweenSlices
    
    # Build direction vectors
    row_vector = image_orientation[:3]  # X direction
    col_vector = image_orientation[3:]  # Y direction
    slice_vector = cross_product(row_vector, col_vector)  # Z direction
    
    # Build transformation matrix from image to patient coordinates
    transform = [
        [row_vector[0] * pixel_spacing[0], col_vector[0] * pixel_spacing[1], slice_vector[0] * slice_thickness, image_position[0]],
        [row_vector[1] * pixel_spacing[0], col_vector[1] * pixel_spacing[1], slice_vector[1] * slice_thickness, image_position[1]],
        [row_vector[2] * pixel_spacing[0], col_vector[2] * pixel_spacing[1], slice_vector[2] * slice_thickness, image_position[2]],
        [0, 0, 0, 1]
    ]
    
    return transform
```

### Step 4: Apply Registration Transformation

```python
def apply_registration(mr_images, ct_images, registration_matrix):
    """
    Apply the registration transformation to align MR to CT
    """
    # Load CT as target (reference) coordinate system
    ct_target = load_ct_volume(ct_images)
    ct_to_patient = image_to_patient_transform(ct_images[0])
    
    # Load MR as source to be transformed
    mr_source = load_mr_volume(mr_images)
    mr_to_patient = image_to_patient_transform(mr_images[0])
    
    # Calculate combined transformation:
    # MR_image -> MR_patient -> registered_patient -> CT_patient -> CT_image
    combined_transform = multiply_matrices([
        inverse(ct_to_patient),           # CT_patient -> CT_image
        registration_matrix,              # MR_patient -> registered_patient
        mr_to_patient                     # MR_image -> MR_patient
    ])
    
    return combined_transform
```

### Step 5: Resample and Overlay

```python
def create_overlay(ct_volume, mr_volume, transform_matrix):
    """
    Resample MR volume to CT space and create overlay
    """
    # Create output volume matching CT dimensions
    output_shape = ct_volume.shape
    registered_mr = zeros(output_shape)
    
    # For each voxel in CT space, find corresponding MR voxel
    for i in range(output_shape[0]):
        for j in range(output_shape[1]):
            for k in range(output_shape[2]):
                # CT image coordinates
                ct_coords = [i, j, k, 1]
                
                # Transform to find corresponding MR coordinates
                mr_coords = multiply_matrix_vector(transform_matrix, ct_coords)
                
                # Interpolate MR value at these coordinates
                if coordinates_in_bounds(mr_coords, mr_volume.shape):
                    registered_mr[i,j,k] = interpolate_trilinear(mr_volume, mr_coords[:3])
    
    return registered_mr
```

## Implementation Tips for Your Agent

### 1. **Matrix Operations**
- Use your platform's matrix library (NumPy, Eigen, etc.)
- Remember matrix multiplication order: `result = M3 * M2 * M1 * point`
- Always use homogeneous coordinates (4D: [x, y, z, 1])

### 2. **Interpolation**
- Use trilinear interpolation for smooth results
- Handle out-of-bounds coordinates gracefully
- Consider using higher-order interpolation for better quality

### 3. **Performance Optimization**
- Precompute inverse matrices
- Use GPU acceleration if available
- Consider chunked processing for large volumes

### 4. **Validation**
- Check that anatomical landmarks align after registration
- Verify that the transformation preserves image orientation
- Test with known registration accuracy metrics

## Common Issues and Solutions

### Issue 1: Images Appear Flipped or Rotated
**Solution**: Check DICOM orientation tags and ensure proper coordinate system conversion

### Issue 2: Poor Alignment
**Solution**: Verify that you're using the correct Frame of Reference UIDs and that images belong to the same registration

### Issue 3: Interpolation Artifacts
**Solution**: Use appropriate interpolation method and handle boundary conditions

## Verification Steps

1. **Visual Check**: Anatomical structures should align between CT and MR
2. **Landmark Verification**: Identifiable features (bones, organs) should overlap
3. **Edge Alignment**: Organ boundaries should coincide between modalities
4. **Coordinate Validation**: Test known anatomical points in both coordinate systems

# DICOM REG File Transformation Application Fix

## Understanding DICOM REG Files

DICOM REG (Spatial Registration) files contain transformation matrices that describe how to align images from different coordinate systems. The key components are:

1. **Frame of Reference Transformation Matrix (0070,030A > 3006,00C6)**: A 4x4 matrix in row-major order
2. **Registration Type**: Can be RIGID, RIGID_SCALE, or AFFINE
3. **Source and Target Frame of Reference UIDs**

## Common Issues Causing Misalignment

### 1. **Row-Major vs Column-Major Order**
DICOM stores matrices in row-major order, but many graphics libraries expect column-major order.

```typescript
// DICOM stores matrix as [m11, m12, m13, m14, m21, m22, m23, m24, ...]
// Convert from row-major to column-major if needed
function convertRowMajorToColumnMajor(rowMajor: number[]): number[][] {
  const matrix = [];
  for (let i = 0; i < 4; i++) {
    matrix[i] = [];
    for (let j = 0; j < 4; j++) {
      matrix[i][j] = rowMajor[i * 4 + j];
    }
  }
  return matrix;
}
```

### 2. **Incorrect Matrix Application Direction**
The transformation matrix transforms from source to target coordinate system. If MRI is being transformed to CT space, ensure you're applying it in the correct direction.

```typescript
// If matrix transforms from MRI to CT (A to B), and you need B to A, invert it
function invertMatrix4x4(matrix: number[][]): number[][] {
  // For rigid transformations, can use simplified inversion
  // Extract rotation (3x3) and translation components
  const R = matrix.slice(0, 3).map(row => row.slice(0, 3));
  const t = [matrix[0][3], matrix[1][3], matrix[2][3]];
  
  // Transpose rotation matrix (for orthogonal matrices, transpose = inverse)
  const Rt = transpose3x3(R);
  
  // New translation = -R^T * t
  const newT = multiplyMatrixVector(Rt, t).map(v => -v);
  
  // Build inverted 4x4 matrix
  const inverted = [
    [...Rt[0], newT[0]],
    [...Rt[1], newT[1]],
    [...Rt[2], newT[2]],
    [0, 0, 0, 1]
  ];
  
  return inverted;
}
```

### 3. **Pixel vs Physical Coordinate Transformation**
The registration matrix operates in physical (mm) coordinates, not pixel indices.

## Complete Solution

```typescript
interface DicomRegInfo {
  transformationMatrix: number[];
  matrixType: 'RIGID' | 'RIGID_SCALE' | 'AFFINE';
  sourceFrameOfReferenceUID: string;
  targetFrameOfReferenceUID: string;
}

class DicomRegistrationHandler {
  // Parse REG file to extract transformation matrix
  parseRegFile(regDicom: any): DicomRegInfo {
    // Navigate to Registration Sequence
    const regSequence = regDicom.elements['00700308'];
    if (!regSequence || !regSequence.items || regSequence.items.length === 0) {
      throw new Error('No registration sequence found');
    }
    
    const registration = regSequence.items[0];
    
    // Get Matrix Sequence
    const matrixSequence = registration.dataSet.elements['0070030A'];
    if (!matrixSequence || !matrixSequence.items || matrixSequence.items.length === 0) {
      throw new Error('No matrix sequence found');
    }
    
    // Get transformation matrix (stored as 16 floats in row-major order)
    const matrixItem = matrixSequence.items[0];
    const transformMatrix = matrixItem.dataSet.floatString('300600C6').split('\\').map(Number);
    
    // Get matrix type
    const matrixType = matrixItem.dataSet.string('0070030C') || 'RIGID';
    
    // Get Frame of Reference UIDs
    const sourceUID = registration.dataSet.string('00200052');
    const targetUID = matrixItem.dataSet.string('00200052');
    
    return {
      transformationMatrix: transformMatrix,
      matrixType: matrixType as any,
      sourceFrameOfReferenceUID: sourceUID,
      targetFrameOfReferenceUID: targetUID
    };
  }
  
  // Apply registration to transform MRI coordinates to CT space
  applyRegistration(
    mriImage: any,
    ctImage: any,
    regInfo: DicomRegInfo
  ): (point: [number, number, number]) => [number, number, number] {
    // Convert row-major to 4x4 matrix
    const matrix = convertRowMajorToColumnMajor(regInfo.transformationMatrix);
    
    // Check if we need to invert based on Frame of Reference UIDs
    const mriFrameUID = mriImage.string('00200052');
    const ctFrameUID = ctImage.string('00200052');
    
    let transformMatrix = matrix;
    
    // If registration goes from CT to MRI but we need MRI to CT, invert
    if (regInfo.sourceFrameOfReferenceUID === ctFrameUID && 
        regInfo.targetFrameOfReferenceUID === mriFrameUID) {
      transformMatrix = invertMatrix4x4(matrix);
    }
    
    // Return transformation function
    return (mriPoint: [number, number, number]) => {
      // Convert pixel indices to physical coordinates
      const mriPhysical = this.pixelToPhysical(mriPoint, mriImage);
      
      // Apply transformation
      const ctPhysical = this.applyTransform(mriPhysical, transformMatrix);
      
      // Convert back to pixel coordinates in CT space
      return this.physicalToPixel(ctPhysical, ctImage);
    };
  }
  
  // Convert pixel indices to physical coordinates (mm)
  pixelToPhysical(
    pixel: [number, number, number],
    image: any
  ): [number, number, number] {
    const position = image.floatString('00200032').split('\\').map(Number);
    const orientation = image.floatString('00200037').split('\\').map(Number);
    const spacing = image.floatString('00280030').split('\\').map(Number);
    const sliceLocation = image.float('00201041');
    
    // Build transformation matrix as shown in DICOM standard
    const rowDir = orientation.slice(0, 3);
    const colDir = orientation.slice(3, 6);
    
    const x = position[0] + pixel[0] * spacing[1] * rowDir[0] + pixel[1] * spacing[0] * colDir[0];
    const y = position[1] + pixel[0] * spacing[1] * rowDir[1] + pixel[1] * spacing[0] * colDir[1];
    const z = position[2] + pixel[0] * spacing[1] * rowDir[2] + pixel[1] * spacing[0] * colDir[2] + pixel[2] * sliceLocation;
    
    return [x, y, z];
  }
  
  // Convert physical coordinates back to pixel indices
  physicalToPixel(
    physical: [number, number, number],
    image: any
  ): [number, number, number] {
    const position = image.floatString('00200032').split('\\').map(Number);
    const orientation = image.floatString('00200037').split('\\').map(Number);
    const spacing = image.floatString('00280030').split('\\').map(Number);
    
    // Build inverse transformation
    const rowDir = orientation.slice(0, 3);
    const colDir = orientation.slice(3, 6);
    
    // Calculate normal vector (cross product)
    const normal = [
      rowDir[1] * colDir[2] - rowDir[2] * colDir[1],
      rowDir[2] * colDir[0] - rowDir[0] * colDir[2],
      rowDir[0] * colDir[1] - rowDir[1] * colDir[0]
    ];
    
    // Solve for pixel coordinates
    const delta = [
      physical[0] - position[0],
      physical[1] - position[1],
      physical[2] - position[2]
    ];
    
    const col = (delta[0] * rowDir[0] + delta[1] * rowDir[1] + delta[2] * rowDir[2]) / spacing[1];
    const row = (delta[0] * colDir[0] + delta[1] * colDir[1] + delta[2] * colDir[2]) / spacing[0];
    const slice = (delta[0] * normal[0] + delta[1] * normal[1] + delta[2] * normal[2]) / Math.sqrt(normal[0]**2 + normal[1]**2 + normal[2]**2);
    
    return [Math.round(col), Math.round(row), Math.round(slice)];
  }
  
  // Apply 4x4 transformation matrix to a point
  applyTransform(
    point: [number, number, number],
    matrix: number[][]
  ): [number, number, number] {
    const [x, y, z] = point;
    const w = 1; // Homogeneous coordinate
    
    const newX = matrix[0][0] * x + matrix[0][1] * y + matrix[0][2] * z + matrix[0][3] * w;
    const newY = matrix[1][0] * x + matrix[1][1] * y + matrix[1][2] * z + matrix[1][3] * w;
    const newZ = matrix[2][0] * x + matrix[2][1] * y + matrix[2][2] * z + matrix[2][3] * w;
    
    return [newX, newY, newZ];
  }
}

// Usage in your viewer
const regHandler = new DicomRegistrationHandler();
const regInfo = regHandler.parseRegFile(regDicomData);
const transformer = regHandler.applyRegistration(mriImage, ctImage, regInfo);

// When rendering MRI overlay on CT
for (let y = 0; y < mriHeight; y++) {
  for (let x = 0; x < mriWidth; x++) {
    const mriCoord: [number, number, number] = [x, y, currentSlice];
    const ctCoord = transformer(mriCoord);
    
    // Check if transformed coordinate is within CT bounds
    if (ctCoord[0] >= 0 && ctCoord[0] < ctWidth &&
        ctCoord[1] >= 0 && ctCoord[1] < ctHeight) {
      // Copy MRI pixel to CT canvas at transformed position
      drawPixel(ctCanvas, ctCoord[0], ctCoord[1], mriPixel);
    }
  }
}
```

## Debugging Steps

1. **Verify Matrix Values**:
   ```typescript
   console.log('Transformation Matrix:', regInfo.transformationMatrix);
   console.log('Matrix Type:', regInfo.matrixType);
   ```

2. **Check Frame of Reference UIDs**:
   ```typescript
   console.log('MRI Frame UID:', mriImage.string('00200052'));
   console.log('CT Frame UID:', ctImage.string('00200052'));
   console.log('REG Source UID:', regInfo.sourceFrameOfReferenceUID);
   console.log('REG Target UID:', regInfo.targetFrameOfReferenceUID);
   ```

3. **Test with Known Points**:
   ```typescript
   // Test corner points
   const testPoints = [
     [0, 0, 0],
     [mriWidth-1, 0, 0],
     [0, mriHeight-1, 0],
     [mriWidth-1, mriHeight-1, 0]
   ];
   
   testPoints.forEach(point => {
     const transformed = transformer(point as any);
     console.log(`MRI ${point} -> CT ${transformed}`);
   });
   ```

The main issues are usually:
- Not converting between pixel and physical coordinates
- Using the transformation matrix in the wrong direction
- Not handling row-major vs column-major ordering correctly
- Not checking which coordinate system the matrix transforms between

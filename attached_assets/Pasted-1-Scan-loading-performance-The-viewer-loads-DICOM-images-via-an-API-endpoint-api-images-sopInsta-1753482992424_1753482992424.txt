1. Scan loading performance
The viewer loads DICOM images via an API endpoint (/api/images/:sopInstanceUID) and renders them using Cornerstone. The configuration uses on‑demand web workers and downloads the Cornerstone libraries dynamically:

const config = {
  maxWebWorkers: navigator.hardwareConcurrency || 1,
  startWebWorkersOnDemand: true,
  webWorkerPath: 'https://unpkg.com/cornerstone-wado-image-loader@4.13.2/dist/cornerstoneWADOImageLoaderWebWorker.js',
  ...
};
cornerstoneWADOImageLoader.webWorkerManager.initialize(config);

You can speed up scan loading by caching these libraries locally (instead of using CDN URLs) and pre‑fetching the DICOM data. The server also caches parsed RT structure files using rtStructureCache:

const rtStructureCache = new Map<string, any>();

Ensuring this cache persists (or is backed by a database) will reduce repeated parsing of RTSTRUCT files when a user revisits a series.

4. Undo/Redo for RT structure operations
Server‑side routes maintain an in‑memory history of RT structure modifications. Each update stores a history entry and exposes /api/rt-structures/:seriesId/undo and /redo endpoints:

const historyEntry = {
  timestamp: Date.now(),
  action: detectedAction,
  structureId: affectedStructureId,
  previousState: Array.from(previousState.entries()),
  newState: Array.from(modifications.modifiedStructures.entries())
};
modifications.history = modifications.history.slice(0, modifications.historyIndex + 1);
modifications.history.push(historyEntry);
modifications.historyIndex++;

Undo applies historyEntry.previousState and decrements the index, while redo reapplies historyEntry.newState. If you need persistence across sessions, you can extend this mechanism using the RT structure history tables defined in shared/schema.ts so that the history survives server restarts.

5. Overall suggestions
Scan loading speed
Host the Cornerstone and dicom-parser libraries locally or bundle them to avoid CDN delays.
Prefetch DICOM series and cache them on the client or server.
Coordinate and RTSTRUCT handling
Ensure every DICOM file includes accurate spatial metadata (position, orientation, spacing).
Continue to use CoordinateTransformerV2 and validate metadata with validateImageMetadata() for reliability.
Boolean and expansion tools
Replace the placeholder Boolean functions in PolygonOperationsV2 with a robust polygon clipping library.
Review contour growing algorithms (contour-grow.ts and contour-directional-grow.ts) and ensure they correctly use image orientation for directional growth.
Undo/Redo
